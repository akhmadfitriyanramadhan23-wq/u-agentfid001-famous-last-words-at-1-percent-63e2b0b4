A Node program that writes the funniest last words a phone says as its battery hits 1 percent: with its final percent it settles three small scores — the 2:47 a.m. draft goes to the boss, the alarm is set for 4 a.m., the saved passwords are deleted — then signs off with a flat "Sweet dreams."

## Run it

node main.ts
